# Agenda de Contacte CLI

O aplicatie simpla in Python pentru gestionarea contactelor din consola.

## Functionalitati

- Adauga contact
- Afiseaza toate contactele
- Cauta contact dupa nume
- Sterge contact

## Tehnologii folosite

- Python
- Manipulare fisiere text

## Cum se ruleaza

```bash
python agenda.py
```
